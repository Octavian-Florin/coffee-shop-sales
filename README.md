# Coffee Shop Sales Analytics Engineering Project

## 📊 Project Overview
This project demonstrates an end-to-end Analytics Engineering workflow using modern data stack tools. It transforms raw coffee shop sales data into clean, structured dimensional models designed for business intelligence and reporting.

## 🛠️ Tech Stack & Tools
- **Database & Warehousing:** PostgreSQL
- **Transformation & Modeling:** dbt (data build tool)
- **Data Visualization:** Power BI
- **Version Control:** Git & GitHub

## 🏗️ Architecture & Workflow
1. **Data Modeling:** Designed and implemented a dimensional data model (Star Schema) separating raw data into clean staging layers and analytical marts.
2. **Transformations (dbt):** Built modular SQL models, applied primary/foreign key relationships, and implemented automated data quality tests (`unique`, `not_null`).
3. **Visualization (Power BI):** Connected the transformed data mart to Power BI to build an executive dashboard tracking key metrics such as total revenue, daily transaction trends, average order value (AOV), and top-performing products.

## 📈 Key Insights & Dashboard
The interactive Power BI dashboard provides stakeholders with immediate visibility into sales performance across different locations and product categories, helping optimize inventory and operational decisions.
